# CineBook 🎬

A production-grade, end-to-end **movie ticket booking platform** built as a learning project to demonstrate real-world backend engineering and system design concepts.

---

## Tech Stack

| Layer | Technology |
|---|---|
| **Frontend** | React + Vite + Tailwind CSS *(Phase 4)* |
| **Backend** | Node.js + Express.js (Modular Monolith) |
| **Database** | PostgreSQL via Prisma ORM |
| **Cache / Locks** | Redis *(Phase 2)* |
| **Payments** | Razorpay Test Mode *(Phase 3)* |
| **Real-time** | Socket.IO *(Phase 2)* |
| **Auth** | JWT + bcrypt *(Phase 2)* |
| **Testing** | Jest + Supertest + Autocannon |

## Quick Start (Backend)

### 1. Install dependencies

```bash
cd server
npm install
```

### 2. Configure environment

```bash
# Copy the template — never commit .env
cp .env.example .env
```

Edit `server/.env`:

| Variable | Purpose |
|---|---|
| `PORT` | Express server port (default `5000`) |
| `NODE_ENV` | `development` / `test` / `production` |
| `DATABASE_URL` | PostgreSQL connection string |
| `JWT_SECRET` | Long random string for signing JWT tokens |
| `JWT_EXPIRES_IN` | Token validity duration (e.g., `7d`, `24h`) |
| `CLIENT_URL` | React dev server URL for CORS (e.g., `http://localhost:5173`) |

Generate a strong `JWT_SECRET`:
```bash
node -e "console.log(require('crypto').randomBytes(64).toString('hex'))"
```

### 3. Create the database

```bash
# Using psql (adjust username if needed)
createdb cinebook_db
# Or: psql -U postgres -c "CREATE DATABASE cinebook_db;"
```

### 4. Run migrations

```bash
npm run db:migrate
# Applies all migrations in prisma/migrations/ to cinebook_db
```

### 5. Seed sample data

```bash
npm run db:seed
# Inserts movies, theatres, screens, seats, shows, and an admin user
```

### 6. Start development server

```bash
npm run dev
# Starts Express with nodemon (auto-restarts on file changes)
```

### 7. Verify it's running

```bash
curl http://localhost:5000/health
# → {"success":true,"status":"ok",...}

curl http://localhost:5000/health/db
# → {"success":true,"status":"ok","database":"connected","latencyMs":...}
```

## Running Tests

```bash
cd server
npm test
# Runs Jest with Supertest integration tests
```

Tests in `tests/health.test.js` work without a database.
Tests in `tests/schema.test.js` skip database-dependent cases gracefully if Postgres is unavailable.

## Security Notes

- **Never commit `server/.env`** — it is gitignored.
- JWT_SECRET must be a long, random string — never a dictionary word.
- Passwords are stored as bcrypt hashes (cost factor 10) — never plaintext.
- Stack traces and database credentials are never included in API responses in production.
- Card details and payment secrets are never stored in the database.
